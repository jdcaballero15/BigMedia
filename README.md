# Big Media Argentina

Sistema de gestión de inventario, campañas y reservas de publicidad de vía pública.

Esta primera entrega prepara el entorno de desarrollo. Todavía no implementa las historias funcionales ni garantiza disponibilidad de carteles.

## Estructura

- `frontend/`: aplicación React y TypeScript.
- `backend/`: API Django REST Framework.
- `docs/requisitos/`: historias de usuario.
- `docs/superpowers/`: diseño y plan aprobados.
- `docs/operacion/`: instrucciones de trabajo local.
- `analytics/`: vistas para Power BI cuando se desarrollen los reportes.

El documento original de historias y el PDF de referencia permanecen en la carpeta local, fuera de Git.
